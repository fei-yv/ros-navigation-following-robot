# 硬件与接线

本文整理这台 ROS 导航小车的硬件选型与参数、供电拓扑、接线方案和雷达安装位姿，并给出编码器参数的推导与验证方法。如果你打算复刻这个项目，建议在动手装车前通读本文，装车与调试阶段也可以把它当作速查手册。固件侧的参数说明见 [固件参数配置](firmware.md)。

## 编码器计算与验证

固件源码中的计算式为：

```c
Encoder_precision = EncoderMultiples * EncoderAccuracy * GearRatio;
```

因此本车预期为：

```text
4 × 11 × 19 = 836 计数/输出轴一圈
```

该公式直接来自固件源码，并非仅凭变量名推断，具体见 [固件参数配置](firmware.md#减速比编码器轮径和轮距) 一节。装车前可以手转输出轴 10 圈，理论累计计数约 8360；若实测不符，按 [故障排查](troubleshooting.md#编码器计数不是-836-圈) 一节排查。

## 推荐整车供电拓扑

```text
12V 电池
├─ 总开关 ─ 保险丝 A ─ C30D ─ 左/右电机
└─ 总开关 ─ 保险丝 B ─ 主机供电支路 ─ x86 小主机
                                         └─ USB ─ Camsense X1
```

- 两支路并联取电，不能把主机和 C30D 串联。
- C30D 和主机应共地；USB 数据连接通常也会建立信号地。
- 不要用 C30D 的 `5Vout` 给小主机供电。
- 首次台架测试时，主机使用原装 12V/3A 适配器、C30D 使用电池，以隔离电机干扰变量。
- 正式合并电源前，先测电机启动/堵转瞬间主机端的最低电压，并观察主机是否重启、USB 是否掉线、雷达是否断流。

## 主机供电支路如何确定

实测已知的只有：主机标称 12V、5525 接口、原装适配器中心正极；无法确认它是严格 12V 输入还是宽压输入。确定方案前建议按以下步骤操作：

1. 向主机商家索要明确的最低/最高允许输入电压，而不是只问"能不能用 12V"。
2. 用万用表测电池满电、正常工作和欠压保护前的输出范围。
3. 若主机允许的输入范围覆盖完整电池电压范围，可以直连，但仍需做电机干扰测试。
4. 若主机要求稳定 12V，而电池电压会跨过 12V，则采用持续输出能力足够的自动升降压模块。
5. 只有在满电略高于 12V 且主机允许低于 12V 时，才可能用降压方案；需基于厂家输入规格决定。

市面上一些标称 `6～30V` 输入、3.3V/5V/VIN 多路输出的板子，其 VIN 是输入直通，并不会把任意输入稳定为 12V，不能当作主机的 12V 稳压器。

## 电机与编码器接线原则

- 左电机接 Motor A、右电机接 Motor B，Motor C/D 不使用；最终以差速固件的 A/B 通道和实物方向测试为准。
- 首次点动时车轮必须悬空，先单独测试 A，再测试 B。
- 正向速度命令下，两侧轮缘对地的运动方向都应使车体前进。
- 编码器反馈的正负号必须与电机目标方向一致。只交换动力线而不修正编码器方向，可能使闭环形成正反馈并突然满速。
- 任何针序均以 C30D 说明书、接口丝印和电机卖家线序图为准，不要按线色猜测。

## USB 与串口分工

| 用途 | 接口/串口 | 配置 |
|---|---|---|
| STM32 烧录 | C30D **一键下载口**（UART1，板载 USB 转串口） | 曾显示 COM7；端口号会变化 |
| 蓝牙遥控 | C30D USART2，PD5(TX)/PD6(RX) | **9600**、8N1；模块 JDY-31（BLE，3.3V 供电） |
| ROS 底盘通信 | C30D **"与ROS主机通讯"口**（USART3，板载 USB 转串口引出，MCU 引脚 PD8/PD9） | 115200、8N1、无流控；**手机数据线可直插**（2026-08-06 实物确认） |
| 雷达 | Camsense X1 独立 USB | 115200，默认可能成为 `/dev/ttyUSB0` |

> **2026-08-06 实物确认**：板上有 3 个口——① Type-C 树莓派/RDK X5 供电口（仅供电）；② **"与ROS主机通讯"口**（即 ROS/USART3，USB 数据线直插即可）；③ **一键下载口**（烧录用，FlyMcu 显示 COM7）。**注意别把烧录口和 ROS 口插混**。

## 蓝牙遥控（JDY-31）

- 模块：JDY-31，BLE 透传，6 针
- 连接：VCC→3.3V、GND→GND、TX→PD6、RX→PD5
- 波特率：9600（固件 USART2 默认）
- 协议（HEX 字节）：
  - `41 41`：进入 APP 遥控模式（连发两次）
  - `41`=前进、`42`=后退、`43`=右转、`44`=左转、`45`/`46`/`47`/`48`=右上/右下/左上/左下（部分车型不支持斜向）
  - `58`=加速、`59`=减速（±100mm/s）、`5A`(Z)=停车（官方协议；`00` 固件也视为停车）
  - `49`=重力、`4A`=摇杆、`4B`=按键模式切换（`4B` 同时进入转向界面）
- 限制：上电 **10 秒后才接受指令**；使能开关 EN 必须 ON
- **2026-08-03 实测**：蓝牙链路已打通（OLED 显示 "APP"、摇杆可控）。注意 JDY-31 **同一时间只能连一个手机**；固件会锁存最后一个方向指令，松手时 APP 需发 `5A`/`00` 停车。
- 源码位置：`HARDWARE\usartx.c` 中 `USART2_IRQHandler`（约第 878 行）

进入 Ubuntu 后，建议分别为底盘和雷达设置 udev 固定名称，例如 `/dev/c30d`、`/dev/camsense_x1`，不要让启动文件依赖容易互换的 `/dev/ttyUSB0` 和 `/dev/ttyUSB1`。UART3 接口与预期不符时，按 [故障排查](troubleshooting.md#c30d-的-uart3-接口与预期不符) 一节处理。

## 小主机网络与 USB 口规划

- **网络**：小主机使用 USB 无线网卡（B258-1147 / AIC8800DC 爱科微，社区驱动 `aic8800_fdrv`，**无官方 Linux 驱动**）；主机内置的 RTL8188EE 已禁用。驱动安装与稳定性配置要点见下。
- **稳定性配置（2026-08-06 修正）**：`ps_on=N`（关省电）、`he_on=N`（禁 WiFi6 降级 WiFi5）；WiFi5 下 0% 丢包。
- **对项目的影响**：ROS 联调（底盘 USART3、雷达）走 **USB 串口，不依赖 WiFi**；WiFi 只影响：① 以后 apt 安装新包（联网）；② 远程访问（SSH/RDP）；③ 可选扩展功能 ROSAPP（手机 WiFi 遥控，需主机与手机同一网络且网卡稳定）。
- **已知坑**：① 手机 USB 共享网络与 WiFi **不能同时开**（路由冲突）；② 内核大版本升级后网卡驱动需重新编译适配；③ 网卡不识别时拔插 USB 冷重启。
- **USB 口规划**：小主机共 4 个 USB，当前占用 = USB 网卡 + 底盘 ROS 线（ttyACM0/CH9102）+ 雷达（ttyUSB0/CH340）= **3 个，剩 1 个**。**雷达必须直连主机 USB 口，不能过拓展坞**（2026-08-06 联调实测：过拓展坞数据被阻断）。如需接入摄像头，需另配拓展坞并单独验证。

## 首次上电安全底线

驱动轮悬空；总开关触手可及；两支路使用合适保险丝；先断电测短路和极性；禁止把电池电压送入 5V 或信号端；不得在方向、超时停车和速度限幅未验证的情况下落地试车。
